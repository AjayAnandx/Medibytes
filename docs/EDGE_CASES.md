# MediBytes — Edge Cases & Resolutions (Standalone)

> 24+ edge cases with Stage, Risk, and Tool-Tied Resolution. Companion to `PRODUCTION_PLAN_L7.md` and `ARCHITECTURE.md`.
> All resolutions are **tied to chosen production tools** (Faster-Whisper, Deepgram, FerroTERM, MuRIL, Gotenberg, etc.), not generic advice.

---

## How to Use

- **Validation status:** `GREEN >0.95` (auto), `YELLOW 0.85-0.95` (needs glance), `RED <0.85 or failed check` (blocks export).
- **Human Review Gate is MANDATORY:** `POST /v1/export` returns `403` if `status != verified`, even for GREEN.
- **Severity:** `CRITICAL` = patient safety (dose, allergy, diagnosis).

## Implementation Checklist (Per Edge Case)

For each `#`, ensure:
- [ ] **Unit test** in `workers/tests/test_edge_#.py` (e.g., `test_silence_gate`, `test_mg_mcg_flip`)
- [ ] **Integration test** with gold audio snippet (stratified by `noise`, `accent`, `mix`)
- [ ] **Eval harness** reports split metric (e.g., `wer_by_accent`, `negation_f1`)
- [ ] **Alert** (Prometheus) + **Runbook** (infra/runbooks/EDGE_#.md)
- [ ] **UI flag** + **API error code** documented in OpenAPI
